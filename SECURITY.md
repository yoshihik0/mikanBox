# セキュリティ / Security

## 日本語

### 対応する版

セキュリティの修正は、🍊mikanBox の最新リリースにだけ行います。古い版をお使いの場合は、最新リリースへ更新してください。

### 脆弱性の報告

脆弱性を見つけたときは、GitHub の非公開の報告機能からお知らせください。

https://github.com/yoshihik0/mikanBox/security/advisories/new

- 公開の Issue、Pull Request、ディスカッションには、再現手順や攻撃方法を書かないでください。修正を公開するまで、ほかの利用者を危険にさらさないためです。
- 報告には、影響する版、再現の手順、想定される影響を書いてください。
- 一人で開発しているため、返信や修正に時間がかかることがあります。

### 修正の告知

修正はリリースノートでお知らせします。利用者が行う操作（MCP APIキーの作り直しなど）が必要な場合も、リリースノートに書きます。

## English

### Supported versions

Security fixes are made only for the latest release of 🍊mikanBox. If you use an older version, update to the latest release.

### Reporting a vulnerability

Please report vulnerabilities privately through GitHub:

https://github.com/yoshihik0/mikanBox/security/advisories/new

- Do not post reproduction steps or attack details in public issues, pull requests or discussions, so that other users are not put at risk before a fix is released.
- Include the affected version, the steps to reproduce, and the expected impact.
- mikanBox is developed by one person, so replies and fixes may take some time.

### Announcing fixes

Fixes are announced in the release notes, together with anything users need to do (for example, issuing a new MCP API key).
